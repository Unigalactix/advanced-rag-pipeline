# Microsoft Azure Overview

Microsoft Azure is a cloud computing platform that provides infrastructure, platform, and software services through Microsoft-managed data centers. Azure offers virtual machines for running workloads, managed Kubernetes through Azure Kubernetes Service, and serverless computing with Azure Functions.

Azure provides artificial intelligence services through Azure OpenAI Service, which gives access to large language models, and Azure AI Search, which supports search and retrieval over enterprise data. Azure AI Search is often used as the retrieval layer in enterprise retrieval-augmented generation applications.

For storage, Azure Blob Storage holds unstructured objects such as documents and images, while Azure SQL Database provides a managed relational database. Azure regions are geographic groups of data centers, and availability zones inside a region protect applications from a single data center failure.
